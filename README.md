# Cámara Watch

Control de la cámara trasera del RedMagic 11 Pro desde el OnePlus Watch 3.

## Descargas

Cuando esté listo el release **v1.0.0**:

- [APK teléfono](https://github.com/GeorgeNava89/CamaraWatch/releases/download/v1.0.0/CamaraWatch-phone-release.apk)
- [APK reloj](https://github.com/GeorgeNava89/CamaraWatch/releases/download/v1.0.0/CamaraWatch-watch-release.apk)

## Instalación (resumen)

1. Instala el APK del teléfono en el RedMagic (orígenes desconocidos).
2. Empareja el Watch 3 con Wear OS / OnePlus.
3. Sideload del APK del reloj (depuración inalámbrica + Bugjaeger / adb).
4. Abre **Cámara Watch** en el teléfono (permisos de cámara/mic/notificaciones) y déjala abierta.
5. Abre la app en el reloj: preview, **Foto**, **Grabar**.
